## 1. Что это за проект

Генератор синтетических сценариев района со случайно расположенными объектами
(СРО) для исследований космической радиолокационной съёмки (РСА). Версия
пакета — в `sro_generator/__init__.py`. Карта документации:

- `README.md` — установка, запуск, параметры конфигурации;
- `WIKI.md` — подробный построчный разбор архитектуры;
- `CHANGELOG.md` — история изменений по версиям;
- `MIGRATION-1.0-TO-1.1.md`, `BENCHMARK-1.1.md` — миграция и бенчмарки;
- `CONVERGENCE-ANALYSIS.md` — отчёт об исследовании сходимости алгоритма
  планирования кадров РСА (версия 1.2.0).

## 2. Текущее состояние (на 2026-11-26)

- Версия **1.3.0**, ветка `main`; коммиты версии 1.3.0 ещё не созданы
  (изменения в рабочей копии: `monte_carlo.py`, `tests/test_monte_carlo.py`,
  `benchmarks/monte_carlo_convergence.py`, вкладка Streamlit в `app.py`,
  MONTE-CARLO-CONVERGENCE.md, CHANGELOG/README/WIKI). Последний запушенный
  коммит: `55da1a7` (исследование сходимости 1.2.0).
- Модуль `sro_generator/monte_carlo.py`: метод Монте-Карло — сходимость
  оценки средней геометрической полноты покрытия района при досъёмке РСА
  объектов, недоступных оптике (облачность, `cloud_fraction`). Каждый запуск —
  новый случайный сценарий из своего seed; K итераций выбора кадров
  (lazy greedy, тот же выбор, что наивный жадный) — фиксированный бюджет.
  Метрики: полнота досъёмки скрытых объектов C и итоговая геометрическая
  полнота района G (оптика + РСА). Контрольные точки m = 10…1000:
  среднее, std, SEM, 95 %-й t-ДИ; n* = ⌈(z·s/δ)²⌉; критерии сходимости
  (дрейф среднего, наклон ln ДИ от ln m ≈ −0.5). PlacementError обрабатывается
  детерминированной перегенерацией сценария.
- Ключевой результат (сценарий 25×25 км / 60 объектов / 240 кадров,
  облачность 0.4, K = 70, M = 1000, seeds 0…999, greedy): средняя полнота
  района **G = 0.9846 ± 0.0003** (95 %-й ДИ), s ≈ 0.0056; C = 1.0 во всех
  1000 запусках (насыщение: бюджета K хватает на полное покрытие скрытых
  объектов, их 13–37). Среднее сошлось (дрейф 0.00018), неопределённость
  убывает как 1/√M (наклон −0.55). Точность ±1 п.п. достигнута уже при m = 10;
  рекомендация **M = 100–200** (для ±0.1 п.п. — m = 200). Отчёт —
  MONTE-CARLO-CONVERGENCE.md, артефакты в `output/monte_carlo/`.
- Тесты: **219 шт., все зелёные** (28 новых для Монте-Карло).
- Модуль `sro_generator/convergence.py` (1.2.0) сохранён без изменений
  поведения; исследование сходимости алгоритма — CONVERGENCE-ANALYSIS.md:
  итерации достижения порогов с вероятностью ≥ 95 % — 90 % → k=41,
  95 % → k=49, 99 % → k=61; рекомендация **K ≈ 70**; greedy быстрее softmax
  на ~25 %, random — в ~2.8 раза медленнее.

### 2026-11-26 — Релиз 2.1.0: модель объектов съёмки (агент Kimi Code)

- Новый модуль `sro_generator/target_model.py`: четыре закона пространственного
  размещения целевых объектов (uniform — биномиальный процесс; cluster —
  гауссовы группы вокруг равномерных центров; regular — квадратная решётка
  с прореживанием и дрожанием; linear — хорды района + гауссово поперечное
  отклонение). Форма объектов — общее ядро `generate_polygon_shape`;
  ограничения — `pair_placement_ok`; генераторы кандидатов — бесконечные
  потоки; воспроизводимость по seed. Генераторы кандидатов сначала были
  конечными (ровно n штук) — исправлено на бесконечные, иначе отказы
  размещения исчерпывали поток.
- Статистики реализации: d̄ до ближайшего соседа с краевой поправкой
  (граничная полоса), индекс Кларка–Эванса R + z (SE Доннелли), индекс
  дисперсии квадрантов I + χ² (квантили — Уилсон–Хилферти; исправлен баг
  пересчёта вероятности в z), осевой индекс анизотропии R_b (удвоенные углы).
  Исследование `run_target_model_study`: N независимых реализаций, классика
  M*/D̃/σ̃/ε (β=0.95), детерминированная перегенерация нереализуемых seed.
- ВАЖНО: при площадях объектов 0,5–5 км² ограничение непересечения
  регуляризует кластер/линейное размещение (сигнатуры исчезают, размещение
  еле сходится). Исследовательский масштаб — 0,05–0,5 км², 60 объектов,
  район 25×25 км (см. docstring research_params в стенде).
- Стенд `benchmarks/target_distribution_study.py` (N=200 на закон, ~40 с;
  `--quick`). Результаты (N=200, β=0.95): uniform — CSR подтверждён
  (отклонения 0.04/0.06 при номинале 0.05; R = 1.025 [1.016; 1.034]);
  cluster — R = 0.618, I = 5.62; regular — R = 1.418, I = 0.368;
  linear — R = 0.645, I = 3.00, R_b = 0.178 (анизотропия выше прочих).
  Отчёт TARGET-OBJECT-DISTRIBUTION.md; артефакты output/target_distribution/
  (2 CSV, JSON, 4 PNG).
- Третья вкладка «Модель объектов съёмки» в app.py (две прежние без изменений):
  выбор закона, визуализация, таблица геометрии, GeoJSON/JSON на скачивание.
